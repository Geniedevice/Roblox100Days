# Creatures (섬 생물)

> Category: Gameplay · Priority: Vertical Slice · Status: Implemented (2026-10-23) — `CreatureService.lua`, data `Shared/Creatures.lua`, 모형 `Shared/Models.Creature`, 표 `Shared/Loot.lua`

## Overview

섬의 바이옴(시드로 정해진 컨셉)마다 사는 생물이 다르다. 마인크래프트 생물(토끼·양·닭·꿀벌·여우·아르마딜로·낙타·개구리·앵무새·무시룸·삐걱이·아홀로틀·알레이·슬라임·스니퍼 등 17종)을 블록 모형으로 만들었다. 생물은 다치게 할 수 없고, 쓰다듬으면 하트와 함께 도감 "생물"에 남는다. 삐걱이·슬라임 같은 "몬스터"도 순하다(힐링 게임).

## Detailed Rules

1. 섬을 불러오면 섬 생물 표(`Loot.ForIsland`: 컨셉에 사는 종 × 시드 배수, 시드 40%로 떠돌이 1종)에서 8마리를 뽑는다.
2. 서식지: 땅 생물은 숲·집터 청크, 물가 생물(개구리·아홀로틀)은 낚시터 청크 땅에서 태어난다. 나는 생물(꿀벌·앵무새·알레이)은 땅 위 4스터드에 뜬다.
3. 움직임(서버): 2~6초 쉬고, 집에서 4~18스터드 안 땅을 골라 이동한다. 길을 3스터드 칸으로 나눠 칸마다 땅 높이를 다시 재어 언덕·골짜기를 따라간다(`CreatureService.Travel`, 땅이 없는 칸은 직선 높이). Walk = 돌아선 뒤 칸마다 일정 속도, Hop = 칸마다 깡총(0.18초 오르고 0.18초 내림), Fly = 땅 위 4스터드를 유지.
4. 쓰다듬기: 생물을 누르면 `Interact("Pet", 생물)`. 9스터드 안 생물 앞에 서면 프롬프트 "쓰다듬기 · 이름"(E · 게임패드 X · 모바일 버튼, 2026-10-24). 14스터드 안, 같은 생물 1.2초 간격. 하트 입자·분홍 번쩍임·"이름 ♥", 쓰다듬은 사람 도감에 기록(+10코인). 쓰다듬는 동안 2.5초 멈춘다. 친구 섬 생물도 쓰다듬을 수 있다.

| 바이옴(컨셉) | 사는 생물 |
|------|------|
| 들꽃 초원섬 | 토끼, 양, 닭, 꿀벌 |
| 벚꽃 계단섬 | 여우, 토끼, 꿀벌 |
| 눈꽃 봉우리섬 | 눈여우, 아기 북극곰, 토끼 |
| 붉은 메사섬 | 아르마딜로, 낙타 |
| 폭포 정글섬 | 앵무새, 개구리 |
| 창백한 정원섬 | 삐걱이(몬스터), 토끼 |
| 버섯 섬 | 무시룸, 슬라임(몬스터) |
| 자수정 동굴섬 | 알레이, 슬라임(몬스터) |
| 아치 군도 | 닭, 양, 토끼 |
| 이끼 숲섬 | 아홀로틀, 개구리, 꿀벌 |
| 떠돌이 전용 | 스니퍼 |

## Formulas

- 뽑힐 확률 `P(종) = s_종 / Σ`, s = 시드 배수 0.5..1.6. 떠돌이 무게 = 토박이 합 × 0.12(시드 40%일 때만)
- 예) 메사섬(2종), 떠돌이 있음: 떠돌이 ≈ 0.12/1.12 ≈ 10.7% → 8마리 중 한 마리 이상 나올 확률 ≈ 1 − 0.893⁸ ≈ 60%

## Edge Cases

- 서식지 청크가 없으면 숲 청크에서 태어난다. 20번 찾아도 땅이 없으면 그 한 마리는 건너뛴다.
- 이동 목표에 땅이 없으면(섬 끝·나무 위·물 위) 그 이동을 건너뛴다(떨어지지 않는다).
- 섬 주인이 나가면 생물도 지운다.

## Dependencies

- 기대는 것: Island Zones(서식 구역), Loot(시드 표), Collection Dex
- 이것에 기대는 것: Interaction Feedback(Pet), Action Animation(쓰다듬기 동작), Pets(생물 모형과 `CreatureService.Travel` 이동을 도우미 동물이 쓴다, pets.md)

## Tuning Knobs

| 값 | 기본 | 안전 범위 | 영향 |
|----|------|-----------|------|
| `COUNT` | 8 | 4~16 | 섬의 생기, 서버 트윈 비용 |
| `ROAM` | 18스터드 | 8~30 | 생물이 퍼지는 범위 |
| `REST` | 2~6초 | 1~15초 | 움직임 빈도 |
| 떠돌이 확률·무게 | 40%·12% | — | 도감 수집 난이도 |

## Acceptance Criteria

- [x] 창백한 정원섬에 토끼가, 정글섬에 개구리·앵무새가 나오고, 시드에 따라 떠돌이(예: 정글섬에 알레이)가 섞인다(측정).
- [x] 토끼를 쓰다듬으면 `Pet`과 `DexNew 생물 · 토끼`가 온다(측정).
- [ ] 생물 움직임이 휴대폰에서 끊겨 보이지 않는다(ponytail: 서버 트윈, 필요하면 클라이언트 트윈으로).
