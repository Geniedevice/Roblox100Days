# Island Generation (시드 복셀 하늘섬)

> Category: Core · Priority: MVP · Status: Implemented (2026-10-23, voxel rewrite → 청크 섬) — `IslandGen.lua`, `IslandBuilder.lua`, data `Shared/Blocks.lua`, `Shared/IslandConcepts.lua`, client `IslandAmbience`
>
> **2026-10-23 청크 개편**: 본섬은 이제 별 모양 한 덩어리가 아니라 16×16블록 청크 16개(4×4)이고, 청크마다 구역(상점 거리·농장·낚시터·집터·광산·숲)이 있다. 구역·땅 넓히기·시드 획득물은 `island-zones.md`가 정한다. 아래 규칙 중 2(섬 덩어리)·3(마당)·6(호수 자리)·9(나무 자리)는 그 문서로 바뀌었다: 숲 구역만 컨셉 지형, 다른 구역은 평평(광산은 계단 바위산), 호수는 낚시터 청크, 나무·특수 지형은 숲 청크, 밑면은 4×4블록 계단. 짓기는 윗면 1블록 안만 블록마다 Part이고 그 아래는 층마다 합친다(greedy meshing). 자리마다 정하는 무작위는 좌표 해시라 땅을 넓혀도 그대로다.

## Overview

정수 시드 하나가 하늘섬 하나를 정한다. 섬은 3스터드 블록으로 된 마인크래프트식 복셀이고, 시드에서 뽑은 기후가 10가지 컨셉 중 하나를 고른다. 컨셉마다 모양·지층·동굴·나무·땅 장식·하늘 분위기가 다르다. 생성은 마인크래프트 1.18+ 월드 생성 구조(노이즈 라우터, 밀도 함수, 동굴 카버, 표면 규칙, 장식 단계)를 하늘섬에 옮긴 것이다. 저장은 시드만 한다(Pillar 2).

## Detailed Rules

1. **기후 → 컨셉**: `Random.new(seed)`로 T(온도)·H(습도)·E(침식 = 평평함)·W(기묘함)를 0..1로 뽑고, 4차원 기후 공간에서 가장 가까운 컨셉 기후점을 고른다(마인크래프트 다중 노이즈 바이옴 소스와 같은 최근접점 방식).
2. **섬 덩어리**: 본섬 1개 + 컨셉별 0~6개의 떠 있는 작은 섬. 해안선은 각도 θ 위의 fBm으로 흔든 별 모양이라 본섬은 늘 한 덩어리다.
3. **지형 밀도**(블록마다): 아래 Formulas의 밀도가 0보다 크면 땅. 마당(스폰 둘레 x∈[-4,5), z∈[-2,7) 블록)은 3D 노이즈를 끄고 마당 높이로 평평하게 맞춘다(둘레 2블록은 smoothstep으로 섞음).
4. **동굴(카버)**: 윗면에서 3블록 넘게, 밑면에서 2블록 넘게 들어간 곳만 판다(농사 땅은 남는다). 치즈(큰 방, 컨셉 확률), 스파게티(두 노이즈가 동시에 0 근처), 누들(더 가늘고 촘촘한 같은 방식).
5. **특수 지형**: 아치(관통 굴, 윗면 3블록은 다리로 남김), 자수정 정동(심층암 → 방해석 → 자수정 껍질, 바깥으로 열린 틈, 빛나는 송이), 얼음 가시, 쓰러진 통나무(1.21.5), 바위, 징검다리(아치 군도: 본섬에서 작은 섬까지 2×2 발판, 1블록씩 오르내림).
6. **대수층**: 컨셉 확률로 마당·해안을 피한 분지에 호수(수면 = 분지 가운데 윗면, 둘레에 둑). 폭포 확률이면 호수에서 바깥쪽으로 폭 1블록 물길을 내고, 섬 끝에서 떨어지는 폭포(물 판 + 물줄기·물안개 입자)를 단다.
7. **표면 규칙**: 컨셉의 규칙 목록을 위에서부터 보고 조건이 모두 맞는 첫 규칙의 블록을 쓴다. 조건 = Floor(윗면 깊이 ≤ n), Ceiling(밑면 높이 ≤ n), Above/Below(높이, 심층암 경계는 1블록 무작위 흔들림), Steep(이웃과 3블록 이상 차이), Noise(패치 노이즈), Bands(메사 테라코타 띠 + 띠 흔들림 노이즈). 마당 윗면은 컨셉의 Yard 블록.
8. **광맥**: 돌·심층암 속 능선 노이즈 띠는 위쪽 구리·아래쪽 철, 덩어리 노이즈는 석탄. 보이는 밑면·절벽에서만 드러난다.
9. **장식(블록)**: 흔들린 격자로 컨셉 나무(참나무·자작나무·가문비나무·벚나무·창백한 참나무 2×2·정글·진달래·선인장·거대 빨간/갈색 버섯)를 가중치로 심는다. 마당 둘레 1블록, 호수 둘레, 해안 2블록 안에는 심지 않는다.
10. **장식(작은 Part)**: 땅 블록마다 컨셉 확률로 하나: 짧은 풀, 고사리, 꽃, 들꽃(1.21.5), 분홍 꽃잎(1.20), 낙엽 더미(1.21.5), 마른 풀(1.21.5), 죽은 덤불, 반딧불 덤불(1.21.5, 물가에 6배), 눈꽃 Eyeblossom(1.21.4, 빛), 작은 버섯. 매달린 것: 정글 잎 아래 덩굴, 창백한 참나무 잎 아래 창백한 이끼, 이끼 숲 섬 밑면의 빛나는 열매.
11. **짓기**: 6방향 이웃 중 공기나 비치는 블록(물·잎·얼음)이 하나라도 있는 블록만 Part로 만든다. 블록마다 좌표 해시로 밝기를 흔들어 격자가 보인다. 풀·잎 색은 컨셉 Tint(마인크래프트 바이옴 색표). 물 윗면은 0.85블록.
12. **분위기**: 클라이언트는 카메라에서 가장 가까운 섬의 컨셉 Ambience로 안개 색·밀도·헤이즈·색보정을 3초 동안 바꾼다.

## Formulas

- 섬 마스크 `f = 1 − dist / (R · (1 + Coast · fbm(cosθ·L, sinθ·L)))` (중심 1, 해안 0)
- PV(봉우리·골짜기) `pv = 1 − |3·|w| − 2|`, w = 2D 기묘함 노이즈(마인크래프트 정의 그대로)
- 윗면 offset `top = Y + 1 + min(1, 3f) · Hill · (hill · S_E(erosion) + S_PV(pv))`
  - S_E = 침식 스플라인 (0→1.6, 0.35→1.1, 0.7→0.6, 1→0.35): 침식이 낮을수록 언덕이 높다
  - S_PV = PV 스플라인 (−1→−0.3, 0→0, 0.6→0.4, 1→1)
  - 뾰족함 `jag = Jagged · halfNegative(2·ridge − 1) · clamp((f − 0.25)/0.5, 0, 1)`, ridge = 1 − |fbm|
  - 계단 `top = round(top / Terrace) · Terrace`
- 밑면 `bottom = Y − Depth·R · f^0.85 · (0.75 + 0.6 · spike)`
- 밀도 `d = Overhang · noise3(0.11x, 0.16y, 0.11z) + 4 · quarterNegative(0.5 · min(top − y, y − bottom))`, 땅 ⇔ d > 0
  - quarterNegative(v) = v < 0 ? v/4 : v, halfNegative(v) = v < 0 ? v/2 : v (마인크래프트 밀도 함수 연산)
  - 예) 윗면에서 1블록 위(depth −1): 4·(−0.5/4) = −0.5 → 3D 노이즈 > 0.5인 곳만 돌출(절벽 혹·처마)
- 동굴: 치즈 `noise3(0.055) > 0.55`, 스파게티 `|n₁| < 0.09 ∧ |n₂| < 0.09` (0.085), 누들 `|n₁| < 0.05 ∧ |n₂| < 0.05` (0.16)
- 광맥: `|vein| < 0.06` → y > −4 구리, 아니면 철 / `ore > 0.6` → 석탄

## Edge Cases

- 같은 시드는 같은 섬이어야 한다: 난수를 쓰는 반복은 기둥 배열 순서로만 돈다(해시 테이블 순회 순서에 기대지 않는다). 버퍼 비교로 검증했다.
- 호수가 마당·해안과 겹치면 호수를 만들지 않는다. 폭포 물길이 섬 밖으로 나가지 못하면 폭포를 달지 않는다.
- 정동이 마당 가까이 생기면 반대편으로 옮긴다.
- 장식이 마당·농지 위에 생기지 않는다(마당 거리 0 이하 제외). 나무는 마당 둘레 1블록도 비운다.
- 징검다리는 작은 섬이 하나 이상일 때만, 한 번에 1블록 이하 높이 차로 만든다.
- 섬 데이터의 블록 Id가 1바이트를 넘으면 안 된다(현재 50종).
- 섬당 Part가 많다(약 6천): 서버 인원이 늘면 클라이언트가 시드로 직접 짓는 방식으로 바꾼다(IslandBuilder의 ponytail 주석).

## Acceptance Criteria

- [ ] 같은 시드로 두 번 만든 섬의 블록 버퍼와 장식 수가 같다.
- [ ] 시드 300개에서 10개 컨셉이 모두 나오고, 가장 흔한 컨셉이 20%를 넘지 않는다.
- [ ] 마당은 평평한 한 높이이고 농지 9칸과 NPC 2명이 그 위에 선다.
- [ ] 섬 생성은 1회 100ms 이하, 짓기는 섬당 Part 10,000개 이하(16청크 측정: 51~82ms, 6,100~10,000개 — 정글섬이 상한).
- [ ] 메사 섬의 절벽에는 테라코타 띠가, 눈꽃 봉우리섬에는 얼음 가시와 눈 덮인 봉우리가, 자수정 동굴섬에는 바깥에서 보이는 정동 틈이 있다.
- [ ] 폭포가 있는 섬은 물길이 섬 끝까지 이어지고 그 아래로 물이 떨어진다.
- [ ] 다른 컨셉 섬으로 카메라가 옮겨 가면 3초 안에 안개 색이 바뀐다.
