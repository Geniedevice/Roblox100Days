# Island Zones & Expansion (구역·섬 넓히기·시드 획득물)

> Category: Progression · Priority: MVP · Status: Implemented (2026-10-23) — `IslandGen.lua`(청크·구역·구조물), `IslandService.lua`(Rebuild·다음 땅 판), `NpcService.lua`·`Dialogues.lua`(안내인 루미), `FarmService.lua`(밭 열기), data `Shared/Loot.lua`

## Overview

섬은 16×16블록 청크로 되어 있고 시작 섬은 4×4 = 16청크(64×64블록, 192×192스터드)다. 청크마다 구역이 정해져 있어서 어디서 무엇을 하는지 한눈에 보인다: 상점 거리(스폰·노점), 농장, 낚시터, 집터, 광산, 숲. 새 NPC **안내인 루미**가 밭을 열어 주고, 섬 가장자리에 땅(청크)을 붙여 주고, 물고기·광석을 사 준다. 무엇이 잘 나오는지(물고기·광석·작물·생물)는 섬 시드가 정한다(Pillar 2: 세상에 하나뿐인 내 섬).

## Detailed Rules

1. **시작 배치**(줄 = 북→남 cz −2..1, 칸 = 서→동 cx −2..1):

   | | cx −2 | cx −1 | cx 0 | cx 1 |
   |---|---|---|---|---|
   | cz −2 | 광산 | 광산 | 숲 | 숲 |
   | cz −1 | 광산 | 농장 | 상점 거리 | 낚시터 |
   | cz 0 | 숲 | 농장 | 상점 거리 | 낚시터 |
   | cz 1 | 숲 | 숲 | 집터 | 집터 |

2. **구역 지형**: 숲은 컨셉 지형 그대로(언덕·나무·장식). 다른 구역은 마당 높이(YARD = 2)로 평평하고, 광산은 그 위 2블록 계단 바위산(안쪽 구역에서 멀수록 높다, 최대 +14)이다. 구역 경계는 3블록 상자 흐림으로 섞는다. 해안선은 청크 경계를 노이즈로 0~3블록 깎는다.
3. **상점 거리**: 십자 길(가로 z 0·1, 세로 x 7·8), 정원사 모모 노점(초록 천막, 건초), 목수 버니 노점(빨간 천막, 판자), 안내인 루미 + "하늘섬 안내도" 판, 길모퉁이 등불 8개. 스폰 = (8, 8) 북쪽(루미·노점 거리)을 본다.
4. **농장**: 농장 청크마다 3×3 밭 자리 4개(둘레 길), 가운데 허수아비, 건초 더미. 밭 1개가 열린 채 시작하고 루미에게서 연다. 밭 번호 순서 = 시작 청크 밭(스폰에서 가까운 순) → 산 땅의 밭(산 순서). 저장된 농지 번호가 바뀌지 않는다.
5. **낚시터**: 낚시터 청크를 채우는 호수(물가 3.5블록 + 노이즈), 깊이 1~4, 바닥 모래·자갈, 물가 모래. 부두(판자 6칸 + 기둥)가 가로 길 끝에서 호수로 뻗는다. 섬 가장자리에 닿은 낚시터는 컨셉 확률로 물길과 폭포를 단다.
6. **집터**: 첫 집터 청크에 9×9 오두막(조약돌 테두리, 판자 바닥·벽, 통나무 모서리, 유리창, 문 폭 3은 스폰 쪽, 계단식 가문비 지붕, 문 옆 등불 2개). 가구는 집터 구역에만 놓인다.
7. **광산**: 위 4번 바위산. 윗면 3블록 안의 드러난 바위에 광석이 박힌다(옆면 7%, 윗면 1.5%). 자수정 동굴섬은 북서 광산 청크 속에 정동이 있고 스폰 쪽으로 굴이 뚫린다.
8. **구역 팻말**: 농장·낚시터·집터·광산 입구에 이름 팻말(스폰을 본다). 클라이언트는 섬 Model의 `Chunks` 속성(JSON)으로 지금 구역을 알아 핫바와 구역 칩을 바꾼다.
9. **땅 넓히기**: 루미 → "섬 넓히기" → 땅 종류(농장·집터·광산·숲) 선택 → 코인이 있으면 `Frontier` 다음 자리에 청크가 붙는다(남 → 서 → 북 → 동, 낚시터 폭포 쪽은 늦게, 20자리 = 최대 36청크). 지형만 새로 짓고(Rebuild) 밭·가구·NPC·집안일은 그대로 둔다. 대화를 닫고 확장 연출(배너·빛기둥·구름 연기)을 보여 준다. 다음 자리에는 반투명 구름 판과 "다음 땅 · 값" 팻말이 떠 있다.
10. **결정성**: 순서가 고정된 값(컨셉·모양·위성 섬 수)만 `Random.new(seed)`, 자리마다 정하는 값(나무·장식·광석·특수 지형)은 좌표 해시(시드 섞음)다. 땅을 넓혀도 원래 칸의 나무·광석·장식이 움직이지 않는다(위성 섬과 해안 근처 밑면만 바뀐다).
11. **시드 획득물**(`Shared/Loot.ForIsland(seed, concept)`, 섬 모양 rng와 별도 `Random.new(seed ⊕ 0x5F3759DF)`):
    - 물고기: 기본 Weight × 시드 배수(0.5..1.8). 컨셉 전용(Only)은 그 컨셉 섬에서만 나온다. 명물 물고기 1종은 ×3.
    - 광석: 기본 Weight × 컨셉 Bonus × 시드 배수(0.6..1.6). 명물 광석 1종(석탄·다이아몬드 제외)은 ×2.5. 광산 광석 배치와 캐는 결과가 같은 표를 쓴다.
    - 작물: 명물 작물 1종은 거둘 때 25% 확률로 하나 더 얻는다.
    - 생물: 컨셉에 사는 종 × 시드 배수(0.5..1.6). 시드 40%로 다른 바이옴·떠돌이 종 하나가 표의 12% 무게로 들른다.
    - 루미 "이 섬의 명물"이 명물 셋을 알려 준다.

## Formulas

- 땅 값 `ChunkPrice = 200 + 150 × (산 땅 수)` → 200, 350, 500, … 3,050(20번째)
- 밭 값 `FieldPrice = 50 × (연 밭 수)` → 2번째 50, 3번째 100, … 8번째 350
- 광산 높이 `rise = round((3 + 9·smooth(clamp(d/14)) + 2.5·fbm) / 2) × 2`, d = 안쪽 다른 구역 청크까지 거리(블록)
- 호수 `inLake = d_fish − 3.5 + 1.2·fbm`, `inLake > 0`이면 물, 바닥 = `YARD − 1 − min(3, floor(0.7·inLake))`
- 밑면은 4×4블록 칸마다 한 깊이: `bottom = YARD − 2 − Depth·g^0.85·(0.75 + 0.6·spike)`, `g = clamp((d_edge − 5·Coast)/18)`, Depth = 컨셉 Shape.Depth × 18

|------|------|
| 생성 / 짓기(16청크) | 51~82ms / 61~118ms, 20청크 75ms / 90ms |
| 섬당 Part | 6,100~10,000(땅 블록 5,500~7,300 중 합친 밑면 730~1,740) |
| 땅 4개 추가 뒤 안쪽 48×48×46 블록 | 105,113 같음 / 871 다름(해안 밑면) |

## Edge Cases

- 저장된 산 땅에 모르는 구역 이름·숫자가 아닌 좌표가 있으면 건너뛴다(`IslandGen.Chunks`). 같은 자리가 두 번 있으면 한 번만 쓴다.
- Frontier가 다 차면 "섬 넓히기" 선택지가 사라지고, 루미는 "더 붙일 땅이 없어"라고 한다.
- 코인이 모자라면 땅·밭을 붙이지 않고 결과 대사만 보여 준다(코인은 빠지지 않는다).
- 밭 자리가 다 찼으면 "밭 열기"가 사라진다. 농장 땅을 사면 자리가 4개 는다.
- 구역 규칙이 바뀌어 집터 밖에 있게 된 가구는 불러올 때 보관함으로 돌아간다.
- 땅을 넓혀 동쪽 낚시터가 안쪽이 되면 폭포는 사라진다(물길이 섬 끝에 닿지 않으므로).

- 기대는 것: Island Generation(지형·구조물), Data Persistence(`Chunks`·`Fields`·`Mined`), Inventory & Economy, NPC Dialogue & Shops(루미 그래프·행동)
- 이것에 기대는 것: Farming(밭 자리), Housekeeping(집터 구역 검사), Mining(광석 자리), Fishing(호수), Creatures(서식 구역), HUD(구역 칩·핫바), Collection Dex(물고기·광석·생물)

## Tuning Knobs

| 값 | 기본 | 안전 범위 | 영향 |
|----|------|-----------|------|
| `CHUNK_BASE`, `CHUNK_STEP` | 200, 150 | 100~500, 50~300 | 섬이 넓어지는 속도 |
| `FIELD_PRICE` | 50 | 20~150 | 농사 수입이 늘어나는 속도 |
| 광석 박힘 확률(옆/윗면) | 7% / 1.5% | 3~15% / 0~5% | 광산 수입, Part 수 |
| 명물 배수(물고기/광석/작물) | ×3 / ×2.5 / 25% | ×1.5~5 / ×1.5~4 / 10~50% | 섬마다 다른 느낌의 세기 |
| 떠돌이 확률 / 무게 | 40% / 12% | 0~100% / 5~30% | 생물 도감을 채우려고 친구 섬을 찾는 이유 |
