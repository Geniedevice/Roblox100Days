# Island Zones & Expansion (구역·섬 넓히기·시드 획득물)

> Category: Progression · Priority: MVP · Status: Implemented (2026-10-23, 2026-10-24 청크 하나씩 짓기·무작위 자리·무작위 바이옴·광산 없앰) — `IslandGen.lua`(청크·구역·구조물·GenerateChunk), `IslandService.lua`(AddChunk·다음 땅 판), `NpcService.lua`·`Dialogues.lua`(안내인 루미), `FarmService.lua`(밭 열기), data `Shared/Loot.lua`

## Overview

섬은 16×16블록 청크로 되어 있고 시작 섬은 4×4 = 16청크(64×64블록, 192×192스터드)다. 청크마다 구역이 정해져 있어서 어디서 무엇을 하는지 한눈에 보인다: 상점 거리(스폰·노점), 농장, 낚시터, 집터, 숲(광석 바위가 솟는 곳). 새 NPC **안내인 루미**가 밭을 열어 주고, 섬에 붙은 빈 자리에 땅(청크, 바이옴 무작위)을 붙여 주고, 물고기·광석을 사 준다. 무엇이 잘 나오는지(물고기·광석·작물·생물)는 섬 시드가 정한다(Pillar 2: 세상에 하나뿐인 내 섬).

## Detailed Rules

1. **시작 배치**(줄 = 북→남 cz −2..1, 칸 = 서→동 cx −2..1):

   | | cx −2 | cx −1 | cx 0 | cx 1 |
   |---|---|---|---|---|
   | cz −2 | 숲 | 숲 | 숲 | 숲 |
   | cz −1 | 숲 | 농장 | 상점 거리 | 낚시터 |
   | cz 0 | 숲 | 농장 | 상점 거리 | 낚시터 |
   | cz 1 | 숲 | 숲 | 집터 | 집터 |

2. **구역 지형**: 숲은 컨셉 지형 그대로(언덕·나무·장식). 다른 구역은 마당 높이(YARD = 2)로 평평하다(광산 바위산 코드는 남아 있지만 광산 청크가 없어 쓰이지 않는다). 구역 경계는 3블록 상자 흐림으로 섞는다. 해안선은 청크 경계를 노이즈로 0~3블록 깎는다.
3. **상점 거리**: 십자 길(가로 z 0·1, 세로 x 7·8), 정원사 모모 노점(초록 천막, 건초), 목수 버니 노점(빨간 천막, 판자), 안내인 루미 + "하늘섬 안내도" 판, 길모퉁이 등불 8개. 스폰 = (8, 8) 북쪽(루미·노점 거리)을 본다.
4. **농장**: 농장 청크마다 3×3 밭 자리 4개(둘레 길), 가운데 허수아비, 건초 더미. 밭 1개가 열린 채 시작하고 루미에게서 연다. 밭 번호 순서 = 시작 청크 밭(스폰에서 가까운 순) → 산 땅의 밭(산 순서). 저장된 농지 번호가 바뀌지 않는다.
5. **낚시터**: 낚시터 청크를 채우는 호수(물가 3.5블록 + 노이즈), 깊이 1~4, 바닥 모래·자갈, 물가 모래. 부두(판자 6칸 + 기둥)가 가로 길 끝에서 호수로 뻗는다. 섬 가장자리에 닿은 낚시터는 컨셉 확률로 물길과 폭포를 단다.
6. **집터**: 첫 집터 청크에 9×9 오두막(조약돌 테두리, 판자 바닥·벽, 통나무 모서리, 유리창, 문 폭 3은 스폰 쪽, 계단식 가문비 지붕, 문 옆 등불 2개). 가구는 집터 구역에만 놓인다.
7. **광산 → 광석 바위**(2026-10-24): 절벽에 박힌 광석은 찾기·닿기 어려워 광산 구역과 지형 광석(광맥 포함)을 없앴다. 광석은 숲 빈 땅에 시간이 지나면 솟는 바위로 캔다(mining.md). 시작 섬 광산 3청크는 숲, 저장된 광산 땅은 숲으로 읽는다. 자수정 동굴섬은 북서 숲 청크 속에 정동이 있다.
8. **구역 팻말**: 농장·낚시터·집터 입구에 이름 팻말(스폰을 본다). 클라이언트는 섬 Model의 `Chunks` 속성(JSON)으로 지금 구역을 알아 핫바와 구역 칩을 바꾼다.
9. **땅 넓히기**: 루미 → "섬 넓히기" → 땅 종류(농장·집터·숲) 선택 → 코인이 있으면 **다음 땅 자리**(구름 판)에 청크가 붙는다.
   - 자리: 섬에 상하좌우로 붙은 빈 청크 자리(청크 좌표 −4..3 안, 최대 36청크) 중 무작위. 섬을 지을 때와 땅을 산 뒤에 미리 골라 반투명 구름 판과 "다음 땅 · 값" 팻말로 보인다(저장하지 않는다, 다시 들어오면 다시 고른다).
   - 바이옴: 살 때 모든 컨셉 중 무작위 하나를 골라 `profile.Chunks`에 `{ X, Z, Zone, Biome }`로 저장한다. 그 청크는 그 바이옴의 표면 규칙·마당 블록·나무·땅 장식·색(Tint)·언덕 모양·광석 표를 쓴다. 시드가 같아 언덕·동굴 노이즈는 옆 땅과 이어진다.
   - **그 청크만 짓는다**(`IslandService.AddChunk` → `IslandGen.GenerateChunk` → `IslandBuilder.Build(…, 기존 Terrain)`): 섬 전체를 다시 만들지 않는다. 새 청크는 옆 땅 쪽 해안을 깎지 않고, 옆 땅의 깎인 해안 틈(0~3블록, `APRON`)을 땅이 없는 칸만 메운다. 그 자리에 걸친 시작 섬의 떠 있는 작은 섬·폭포 Part는 치운다.
   - 접속할 때도 같다: 시작 섬(시드)을 짓고 산 땅을 산 순서대로 하나씩 더 짓는다(산 순서가 같으면 늘 같은 모양).
   - 밭·가구·NPC·집안일·광석 바위는 그대로다. 대화를 닫고 확장 연출(배너 "농장 · <바이옴> · n청크"·빛기둥·구름 연기)을 보여 준다.
10. **결정성**: 순서가 고정된 값(컨셉·모양·위성 섬 수)만 `Random.new(seed)`, 자리마다 정하는 값(나무·장식·특수 지형)은 좌표 해시(시드 섞음)다. 산 청크의 자리·바이옴만 무작위이고 저장된다. 땅을 넓혀도 원래 칸의 Part는 하나도 바뀌지 않는다(새 청크 자리의 위성 섬·폭포만 치운다).
11. **시드 획득물**(`Shared/Loot.ForIsland(seed, concept)`, 섬 모양 rng와 별도 `Random.new(seed ⊕ 0x5F3759DF)`):
    - 물고기: 기본 Weight × 시드 배수(0.5..1.8). 컨셉 전용(Only)은 그 컨셉 섬에서만 나온다. 명물 물고기 1종은 ×3.
    - 광석: 기본 Weight × 컨셉 Bonus × 시드 배수(0.6..1.6). 명물 광석 1종(석탄·다이아몬드 제외)은 ×2.5. 광석 바위는 그 땅 바이옴의 표(`Loot.ForIsland(seed, 바이옴)`)를 쓴다.
    - 작물: 명물 작물 1종은 거둘 때 25% 확률로 하나 더 얻는다.
    - 생물: 컨셉에 사는 종 × 시드 배수(0.5..1.6). 시드 40%로 다른 바이옴·떠돌이 종 하나가 표의 12% 무게로 들른다.
    - 루미 "이 섬의 명물"이 명물 셋을 알려 준다.

## Formulas

- 땅 값 `ChunkPrice = 200 + 150 × (산 땅 수)` → 200, 350, 500, … 3,050(20번째)
- 밭 값 `FieldPrice = 50 × (연 밭 수)` → 2번째 50, 3번째 100, … 8번째 350
- 호수 `inLake = d_fish − 3.5 + 1.2·fbm`, `inLake > 0`이면 물, 바닥 = `YARD − 1 − min(3, floor(0.7·inLake))`
- 밑면은 4×4블록 칸마다 한 깊이: `bottom = YARD − 2 − Depth·g^0.85·(0.75 + 0.6·spike)`, `g = clamp((d_edge − 5·Coast)/18)`, Depth = 컨셉 Shape.Depth × 18

|------|------|
| 생성 / 짓기(16청크) | 51~82ms / 61~118ms, 20청크 75ms / 90ms |
| 섬당 Part | 6,100~10,000(땅 블록 5,500~7,300 중 합친 밑면 730~1,740) |
| 땅 4개 추가 뒤 안쪽 48×48×46 블록 | 105,113 같음 / 871 다름(해안 밑면) |
| 땅 하나 사기(2026-10-24, Edit 시드 12345) | 통째로 다시 짓기 생성 67ms + 짓기 78ms·Part 10,594개 새로 → 청크 하나 생성 2ms + 짓기 3ms·Part 287개 더 |
| 땅 하나 사기(Play, 밭·동물 다시 맞추기 포함) | 13ms, 새 Part 399개, 기존 Terrain 그대로 |

## Edge Cases

- 저장된 산 땅에 모르는 구역 이름·숫자가 아닌 좌표가 있으면 건너뛴다(`IslandGen.Chunks`). 같은 자리가 두 번 있으면 한 번만 쓴다.
- 붙일 자리가 없으면(36청크 또는 −4..3 칸이 다 참) "섬 넓히기" 선택지가 사라지고, 루미는 "더 붙일 땅이 없어"라고 한다.
- 저장된 산 땅에 바이옴이 없으면(2026-10-24 전) 섬 컨셉으로 짓는다. 저장된 "Mine" 땅은 숲으로 읽는다.
- 바이옴이 다른 숲이 맞닿으면 경계에서 언덕 높이가 달라 낮은 절벽이 생길 수 있다(바이옴 경계로 둔다).
- 코인이 모자라면 땅·밭을 붙이지 않고 결과 대사만 보여 준다(코인은 빠지지 않는다).
- 밭 자리가 다 찼으면 "밭 열기"가 사라진다. 농장 땅을 사면 자리가 4개 는다.
- 구역 규칙이 바뀌어 집터 밖에 있게 된 가구는 불러올 때 보관함으로 돌아간다.
- 낚시터 동쪽에 땅을 사면 그 자리에 걸친 폭포 Part는 치워진다(물길은 새 땅 가장자리에서 끝난다).

## Dependencies

- 기대는 것: Island Generation(지형·구조물), Data Persistence(`Chunks`(바이옴 포함)·`Fields`), Inventory & Economy, NPC Dialogue & Shops(루미 그래프·행동)
- 이것에 기대는 것: Farming(밭 자리), Housekeeping(집터 구역 검사), Mining(숲 청크·바이옴 광석 표), Fishing(호수), Creatures(서식 구역), HUD(구역 칩·핫바), Collection Dex(물고기·광석·생물)

## Tuning Knobs

| 값 | 기본 | 안전 범위 | 영향 |
|----|------|-----------|------|
| `CHUNK_BASE`, `CHUNK_STEP` | 200, 150 | 100~500, 50~300 | 섬이 넓어지는 속도 |
| `FIELD_PRICE` | 50 | 20~150 | 농사 수입이 늘어나는 속도 |
| `IslandGen.MAX_CHUNKS`, `BOUND` | 36, 4 | 20~64, 3~6 | 섬이 얼마나 넓어지나(슬롯 간격 1,200스터드 안) |
| `APRON` | 3블록 | 0~4 | 새 청크가 옆 땅 해안 틈을 메우는 폭(해안 깎임 최대치와 같게) |
| 명물 배수(물고기/광석/작물) | ×3 / ×2.5 / 25% | ×1.5~5 / ×1.5~4 / 10~50% | 섬마다 다른 느낌의 세기 |
| 떠돌이 확률 / 무게 | 40% / 12% | 0~100% / 5~30% | 생물 도감을 채우려고 친구 섬을 찾는 이유 |

## Acceptance Criteria

- [x] 새 섬은 16청크이고 표의 구역 배치를 따른다(밭 자리 8, 낚시터 호수·부두, 오두막, 노점 2, 북쪽·서쪽 숲).
- [x] 루미 대화에서 팔기 → 밭 열기를 하면 코인이 빠지고 농지가 9칸 늘며 대화가 닫히고 확장 신호가 온다.
- [x] 땅을 사면 섬에 붙은 빈 자리에 그 청크만 지어지고(기존 Terrain·Part 그대로), 바이옴이 저장되며, 농장 땅이면 밭 자리가 4개 는다(2026-10-24 Play 스모크).
- [ ] 새 바이옴 땅이 옆 땅과 틈 없이 이어져 보인다(3D 화면 확인 필요).
- [x] 같은 시드면 명물 물고기·광석·작물과 생물 표가 같다. 다른 컨셉 섬은 전용 물고기·생물이 다르다.
- [ ] 휴대폰에서 다음 땅 판과 팻말이 섬 밖 하늘에서 읽힌다(3D 화면 확인 필요).
