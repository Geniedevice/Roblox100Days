# Fishing (낚시)

> Category: Gameplay · Priority: MVP · Status: Implemented (2026-10-23) — `FishService.lua`, data `Shared/Fish.lua`·`Shared/Loot.lua`, client `ActivityClient`(찌·"!"·물고기 모형)·`Hud`(당기기 버튼)

## Overview

낚시터 호수를 누르면 찌를 던지고, 잠시 뒤 찌가 쑥 들어가며 "!"가 뜨면 다시 눌러 낚는다. 섬마다(시드) 잘 낚이는 물고기가 다르고, 어떤 물고기는 특정 컨셉 섬에서만 산다. 실패에 벌칙은 없다. 물고기는 안내인 루미가 산다.

## Detailed Rules

1. 내 섬 물 Part를 누르면 `Interact("Cast", 물, 위치)`. 서버가 검사한다: 내 섬 Water 폴더 안, 위치가 그 물 Part 위, 캐릭터에서 45스터드 안.
2. 찌는 2.5~6.5초 뒤 입질한다(`Bite`, 창 1.2초). 입질 뒤 1.2초 + 지연 여유 0.25초 안에 누르면 낚인다(`Reel`, 물을 다시 누르기·아무 데나 누르기·휴대폰 "당기기!" 버튼 모두).
3. 입질 전에 누르면 "너무 일렀어요", 창이 지나면 "놓쳤어요… 다시!"(`Miss`). 다시 던지면 된다.
4. 무엇이 낚이는지: `Loot.Pick(섬 물고기 표, 무작위)` — 시드 배수·컨셉 전용·명물(×3). 처음 낚은 종은 도감 "물고기"에 기록(+10코인).
5. 연출: 던지기 동작(감기 250ms + 던지기 150ms) → 찌가 포물선으로 날아가 900ms에 착수 → 입질 때 찌가 0.6스터드 쑥 + 두 번 튐, "!" 96px(PC "클릭!") → 낚으면 물고기 모형이 두 바퀴 돌며 플레이어 쪽으로, 아이콘이 핫바 물고기 칸으로 날아간다. 희귀(무게 ≤ 2 또는 값 ≥ 30)는 화면 Warm 번쩍임.

| 물고기 | 무게 | 값 | 어디서 |
|------|------|------|------|
| 구름 송사리 / 하늘 붕어 / 무지개 송어 / 별빛 메기 | 40 / 30 / 12 / 8 | 3 / 6 / 15 / 20 | 모든 섬 |
| 벚꽃 잉어 / 얼음 빙어 / 정글 아로와나 / 자수정 가재 | 14씩 | 30 / 25 / 35 / 30 | 벚꽃 계단섬 / 눈꽃 봉우리섬 / 폭포 정글섬 / 자수정 동굴섬 |
| 황금 비늘 잉어 / 낡은 장화 | 1.5 / 6 | 100 / 1 | 모든 섬 |

## Formulas

- 낚일 확률 `P(종) = W_종 × s_종 × (명물 ? 3 : 1) / Σ`, s = 시드 배수 0.5..1.8, 그 섬에 살지 않는 컨셉 전용 종은 0
- 예) 기본 섬(전용 없음) 무게 합 ≈ 97.5 → 황금 잉어 ≈ 1.5/97.5 ≈ 1.5%(시드 배수 1일 때)
- 평균 값(기본 섬, 시드 배수 1) = Σ W·값 / Σ W = 796 / 97.5 ≈ 8.2코인
- 시간당 기대 수입(던지기 주기 ≈ 6초, 성공 90%) ≈ 600회 × 0.9 × 8.2 ≈ 4,400코인/시간 → 농사보다 손이 많이 가는 대신 바로 들어오는 수입

## Edge Cases

- 던진 채 멀리 가도 입질·놓침은 서버 시간대로 끝난다(찌는 사라진다).
- 남의 섬 물에도 던질 수 있다(놀러 간 섬, party-visiting.md). 낚이는 표는 그 섬 것이다.
- 데이터를 못 불러온 상태면 낚아도 아무것도 주지 않는다.
- 같은 사람이 찌를 두 개 띄울 수 없다(던진 상태에서 물을 누르면 당기기).

## Dependencies

- 기대는 것: Island Zones(호수·부두), Inventory & Economy(`Fish_<Id>`), Collection Dex, Loot(시드 표)
- 이것에 기대는 것: NPC Dialogue(루미 매입), HUD(핫바 물고기 칸·당기기 버튼), Interaction Feedback(Cast·Bite·Catch·Miss)
- Party & Visiting: 친구 섬 물에서도 던질 수 있고, 그 섬(시드) 표로 낚인다. 물고기는 낚은 사람 것(`party-visiting.md`)

## Tuning Knobs

| 값 | 기본 | 안전 범위 | 영향 |
|----|------|-----------|------|
| `WAIT_MIN`, `WAIT_MAX` | 2.5, 6.5초 | 1~10초 | 기다림의 길이(힐링 템포) |
| `BITE_WINDOW` | 1.2초 | 0.8~2초 | 유일한 반응 도전의 난이도 |
| `REACH` | 45스터드 | 30~60 | 부두 끝에서 호수 가운데까지 닿는가 |
| 물고기 무게·값 | 위 표 | — | 수입과 희귀함 |

## Acceptance Criteria

- [x] 부두에서 물을 누르면 찌가 뜨고, 입질 뒤 당기면 물고기가 들어온다(측정: 무지개 송어, 하늘 붕어).
- [x] 입질 전에 당기면 "너무 일렀어요", 창이 지나면 "놓쳤어요"가 나오고 아무것도 잃지 않는다.
- [x] 컨셉 전용 물고기는 다른 컨셉 섬의 표에 없다.
- [ ] 휴대폰에서 "당기기!" 버튼이 입질 200ms 안에 점프 버튼 자리에 뜬다(기기 확인 필요).
