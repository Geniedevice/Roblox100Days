# Action Animation

> Category: Gameplay · Priority: Vertical Slice · Status: Implemented (session 2, 2026-10-23)

## Overview

행동마다 캐릭터가 짧게 움직이고(괭이질, 씨앗 심기, 물뿌리기, 뽑기, 놓기), 작물·NPC·UI도 살아 있게 움직인다. 애니메이션 에셋을 올리지 않고 클라이언트에서 관절(Motor6D, 새 아바타는 AnimationConstraint의 Attachment0)과 모델을 트윈으로 움직인다: 업로드한 애니메이션은 소유권 문제가 있고, 관절 트윈은 어느 게임에서나 돈다.

## Detailed Rules

1. 신호: 서버의 `Feedback(kind, {Player, Position, …})`를 모든 클라이언트가 받는다. 각 클라이언트가 그 플레이어 캐릭터를 직접 움직인다(관절 변경은 복제되지 않으므로 모두가 같은 신호로 그린다).
2. 동작 표(R15 기준, R6은 어깨만):

| kind | 동작 | 길이 | 손에 드는 것 |
|------|------|------|------|
| Till | 팔을 머리 위로 → 내려찍기, 허리 숙임 | 0.45초 | 괭이 |
| Plant | 무릎 굽혀 앉았다 일어남(Root 아래로), 손 앞으로 | 0.5초 | — |
| Water | 팔 앞으로 뻗고 기울이기 | 0.6초 | 물뿌리개 |
| Harvest, Clean | 허리 숙였다 뽑아 올리기 | 0.45초 | — |
| Place, Pickup | 두 팔 앞으로 내밀기 | 0.35초 | — |

3. 동작 전에 캐릭터가 대상 쪽을 본다(자기 캐릭터만 회전, 서버에 복제됨).
4. 동작이 끝나면 관절을 원래 C0로 되돌린다. 같은 캐릭터에 새 동작이 오면 이전 동작을 끊고 새로 시작한다.
5. 작물: 단계가 바뀌어 새 모델이 생기면 0.2배 → 1.15배 → 1배로 튀어 오른다(0.35초). 3단계 작물은 좌우로 살랑 흔들린다(±4°, 2.5초 주기, 작물마다 위상 다름).
6. NPC: 숨 쉬듯 위아래 0.15스터드(3초 주기). 대화가 시작되면 플레이어를 보고 손을 흔든다.
7. NPC끼리 잡담: 같은 섬의 NPC 두 명이 20초마다 번갈아 말풍선 한 줄(대사 풀에서 순서대로).
8. UI: 대화창은 아래에서 올라오고(0.2초), 대사는 초당 40자로 타이핑된다. 대화창을 누르면 바로 다 보인다.

## Formulas

- 튀어 오름 크기 `s(t)`: 0~0.6 구간 0.2→1.15 (Back easing), 0.6~1 구간 1.15→1
- 흔들림 각 `θ(t) = 4° × sin(2π t / 2.5 + φ)`, φ = 작물 위치 해시
- 타이핑 시간 = 글자 수 / 40 초 (예: 40자 대사 = 1초)

## Edge Cases

- 캐릭터가 R6 → 동작을 건너뛴다(관절 이름·축이 R15와 달라 같은 각도로 움직일 수 없다). 입자·소리는 그대로 나온다.
- 동작 중 캐릭터가 죽거나 사라짐 → 트윈을 버리고 아무것도 하지 않는다.
- 다른 플레이어가 멀리(100스터드 밖) 있음 → 그 플레이어 동작은 그리지 않는다.
- 작물 모델이 튀어 오르는 중에 지워짐 → 트윈이 끝까지 안 가도 오류 없이 멈춘다.
- 동작 연타 → 마지막 동작만 보인다(4번 규칙).

## Dependencies

- Farming, Housekeeping, NPC Dialogue & Shops: `Feedback` 신호와 `Crop`·`Npc` 태그를 낸다 (양방향: 각 GDD에 신호 소비자로 이 문서를 적었다)
- Interaction Feedback: 같은 신호를 소리·입자로 그린다(서로 독립)

## Acceptance Criteria

- [ ] 농지를 갈면 0.45초 동안 괭이를 들고 내려찍고, 끝나면 팔이 원래 자리로 돌아온다.
- [ ] 다른 플레이어가 물을 주는 모습이 내 화면에도 보인다.
- [ ] 작물이 자라 단계가 바뀌면 튀어 오르고, 다 자란 작물은 흔들린다.
- [ ] 모모에게 말을 걸면 모모가 나를 보고 손을 흔든다. 대사가 타이핑되고 누르면 바로 다 보인다.
- [ ] 모모와 버니가 20초마다 번갈아 말풍선을 띄운다.
- [ ] 연속으로 5번 눌러도 팔이 이상한 각도로 남지 않는다.
