## 1. HUD Philosophy

일하는 손은 화면 아래에, 쌓이는 보상은 화면 위에 둔다. 가운데는 섬을 보는 자리라 비워 둔다. 숫자는 휙 바뀌지 않는다. 얻은 것(작물·물고기·광석·코인)은 **월드에서 HUD 칸으로 날아와 닿고**, 닿는 순간 카운터가 움직인다(지연 카운터).
- **Visibility principle**: 상황에 따라 보인다(CONTEXTUAL). 섬의 구역이 바뀌면 핫바가 그 구역의 도구와 아이템으로 바뀐다.
- **Rule of Necessity**: HUD 요소는 "다음에 탭할 것을 알려 주거나, 방금 얻은 것이 닿을 자리가 되어 줄 때" 자리를 얻는다.

## 4. HUD Element Specifications

| 요소 | 항상 | 데이터 | 갱신 | 최소 크기 | 겹침 우선 | 색 말고 다른 단서 |

| 토스트 / 배너 / 구역 칩 | 이벤트 때 | `Feedback` | — | 17 / 24 / 15px | 4 / 3 / 6 | 글자 |
| 떠오르는 글자(월드) | 이벤트 때 | `Feedback.Text` | 1.2초 | 26px | 6 | 끌 수 있음 |

**코인 알약 (지연 카운터)**: 왼쪽에 3D 코인 아이콘 36px, 숫자는 FredokaOne, 10,000 이상은 "12.4K"로 줄인다. 값이 바뀌면 (1) 알약 아래에 "+24"(Sun Gold, Gold Deep 테두리) 또는 "−15"(Ink 글자, Coral 테두리) 칩이 바로 뜬다. (2) 날아오는 코인이 있으면 첫 코인이 닿을 때, 없으면 100ms 뒤에 숫자가 굴러가기 시작한다. 길이는 `dur = clamp(250 + 3·|Δ|, 250, 1200) ms`, Quad Out(Δ=3 → 259ms, Δ=240 → 970ms). (3) 굴러가는 동안 숫자 크기는 1.08배다. 다 굴러가면 칩이 200ms 동안 사라진다. 코인이 모자라면 알약이 좌우로 ±8px 흔들리고 Coral 번쩍임이 붙는다.

**아늑함 / 도감 알약 (고스트 막대)**: 알약 안쪽 아래에 높이 6px 막대를 둔다(바탕 Parchment Deep). 아늑함은 **다음 등급까지의 진행**(D<15≤C<45≤B<75≤A<110≤S)을 보여 준다. 값이 늘면 Ghost Gain(255,235,150)이 바로 새 값까지 가고, 본 채움(Leaf / 도감은 Berry)이 350ms(도감은 600ms) 뒤에 500ms(600ms) 동안 따라간다. 값이 줄면 본 채움이 바로 줄고, Ghost Loss(255,170,170)가 400ms 뒤에 500ms 동안 줄어든다. 등급 배지는 지름 28px, 글자 + 색(D 회색 170,160,150 · C Mint · B Sky · A Sun Gold · S Berry→Gold 그라데이션)이다. 등급이 오르면 배지가 X축으로 1→0→1 뒤집히고(200ms) 배너가 뜬다.

**핫바 (도구 칸 + 구역 아이템 칸)**: 맨 왼쪽은 **도구 칸**(Parchment Deep 채움, 자동으로 바뀌고 고를 필요 없음)이고, 오른쪽은 아이템 칸이다. 구역에 따라:
- 농장·광장·야생: 도구 = 괭이/물뿌리개(누를 농지 상태에 따라) / 칸 = 씨앗(3D 작물 + 왼쪽 아래 씨앗 주머니 20px 배지, 오른쪽 아래 "×5", 오른쪽 위 수확 수 금색 원 배지)
- 연못·부두: 도구 = 낚싯대 / 칸 = 가진 물고기 종류(최대 6, 3D 물고기 ×n)
- 광산: 도구 = 곡괭이 / 칸 = 가진 광석 6종(석탄·구리·철·금·자수정·다이아, 3D 광석 블록 ×n, 0개인 종류는 숨김)
- 집(꾸미기 모드): 핫바 대신 꾸미기 트레이가 나온다(같은 자리, 높이 96, 가로 스크롤, 칸 72×80)

구역이 바뀌면 칸이 아래로 사라지고(120ms Quad In) 새 칸이 올라온다(160ms Back Out, 칸마다 30ms 간격). 도구 칸 아이콘은 뒤집히며 바뀐다. 고른 칸은 6px 들리고 1.06배, Leaf 4px 테두리가 붙고 아이콘이 초당 30° 돈다. 개수 0인 씨앗 칸은 아이콘 투명도 0.5, 칸 투명도 0.4로 흐리다. PC는 숫자 키 1~7과 휠, 게임패드는 LB/RB로 고른다. 칸 위에 이름이 600ms 떴다가 사라진다(핫바를 가리지 않게 칸 위 8px).

**입질 프롬프트**: 찌 위에 BillboardGui "!"(FredokaOne 96px, Sun Gold, Cocoa 4px 테두리, `AlwaysOnTop`)가 0 → 1.5 → 1(200ms Back Out)로 튀어나오고 ±8° 흔들린다. 찌가 화면 밖에 있으면 화면 가장자리에 같은 "!"를 72px로 띄운다. 휴대폰은 오른쪽 기둥 자리를 **"당기기!" 버튼**(120×120, Leaf Deep, 흰 글자 24px + Leaf Ink 테두리, 낚싯대 3D 아이콘)이 대신한다. 0.6 → 1.1 → 1(180ms)로 튀어나온 뒤 300ms마다 1↔1.06으로 맥동한다. 버튼 아래 8px 막대는 입질 창(`BiteWindow`, 낚시 GDD 값, 가정 1.2초) 동안 줄어든다. 물을 다시 탭해도, 버튼을 눌러도 당긴다. PC는 "!" 아래에 "클릭!"을 표시하고, 게임패드는 A 버튼이다.

**광석 진행 막대**: 처음 칠 때 나타난다(0.8 → 1, 140ms Back Out). 칸 N개로 된 막대이고, N은 그 광석의 타격 수다(광산 GDD 값, 가정: 석탄 3·구리 4·철 5·금 6·자수정 7·다이아 8). 칸 채움은 광석 색이다. 한 번 칠 때마다 한 칸이 1.3 → 0으로 튀어 사라지고(120ms), 그 자리에 Ghost Loss 고스트가 250ms 남았다가 300ms 동안 줄어든다. 연타 중에는 고스트가 마지막 타격까지 기다린다. 2.5초 동안 치지 않으면 사라진다(남은 칸은 광산 규칙을 따른다).

**확장 축하**: 루미에게 청크(농장·집·광산·숲)를 사면 상점이 닫히고 확장 배너가 뜬다. 340×96 Banner Gold, 왼쪽에 새 구역 색의 3D 복셀 덩어리 아이콘, 제목 "섬이 넓어졌어요!", 부제 "광산 구역 · 5/16". 부제 아래 진행 막대(가진 청크/16)는 고스트로 따라간다. 색종이 24개, 링 2개가 붙는다. 그 뒤 4초 동안 새 청크 방향을 가리키는 화살표 칩 "여기!"를 화면 가장자리에 띄운다. 농지 한 칸 구매는 같은 연출을 60% 크기로 쓴다("밭이 늘었어요! 2/…").

**토스트 / 배너**: 토스트는 Cream 알약 + Cocoa 3px 테두리 + 3D 아이콘 28px(있으면) + 17px 글자다. 등장(y −12에서, 180ms Back Out) → 2200ms 유지 → 퇴장(160ms Quad In). 새 도감 배너(300×84 Banner Gold)는 아이콘이 300ms 동안 **실루엣이었다가 흰색으로 번쩍이며 색이 드러난다**. 도장 찍기 1.6 → 0.92 → 1, 유지 2500ms. 수치는 `interaction-patterns.md`를 따른다.

## 6. Information Hierarchy

꼭 남김: 코인, 핫바, 입질 "!"/당기기. 남기는 게 좋음: 도감·아늑함 알약, 기둥. 숨겨도 됨: 콤보, 구역 칩, 떠오르는 글자(설정으로 끔 → 대신 토스트로 알림). 늘 숨김: 성장 타이머(월드와 토스트가 대신한다).

## 10. Accessibility

- **색맹**: 등급은 글자로, 고른 칸은 들림과 테두리로, 수확 배지는 오른쪽 위 원 모양으로, 고스트 늘어남/줄어듦은 칩의 "+/−" 부호로, 입질은 "!" 글자와 소리로 구분한다. 색에만 기대는 곳은 없다.
- **글자 크기**: 최소 14px. 키우기는 HUD 루트 `UIScale`(100/125/150%)로 한다. Roblox의 `GuiService.PreferredTextSize`가 있으면 그 값으로 시작한다(엔진 참조로 확인 필요).
- **움직임**(설정 "움직임 줄이기", 기본값은 `GuiService.ReducedMotionEnabled`가 있으면 그 값): 카메라 흔들림·FOV 킥·화면 번쩍임·Highlight 번쩍임 → 0. 펀치·튕김·날아가기·색종이 → 끔(값은 150ms 뒤 바로 바뀌고 칩은 남는다). 구역 슬라이드 → 120ms 페이드. 맥동·아이콘 회전 → 멈춤. 입자는 50%로 줄인다. 소리와 글자는 그대로 둔다.
- **자막**: 음성이 없고 대화창 글이 곧 자막이다. 모든 소리에는 화면 신호가 함께 있다(소리만으로 전하는 정보 없음).
- **설정 패널**(기둥의 설정 버튼): 움직임 줄이기(켬/끔), 떠오르는 글자(켬/끔), 콤보 표시(켬/끔), 효과음 크기(0~100%), HUD 크기(100/125/150%). `profile.Settings`에 저장한다.

## 12. Acceptance Criteria

- [ ] 휴대폰 에뮬레이터(667×375)에서 HUD가 조이스틱·점프 버튼 영역과 겹치지 않는다. 기둥 버튼이 점프 버튼 바로 위에 붙는다.
- [ ] 씨앗·가구·물고기·광석·코인·섬 아이콘이 모두 3D ViewportFrame이다. 단색 원은 하나도 남지 않는다. 못 찾은 도감은 검은 실루엣 + "?"로 보인다.
- [ ] 순무 2개를 팔면 "+24" 칩이 바로 뜨고, 첫 코인이 닿을 때 숫자가 굴러가기 시작해 약 320ms 뒤 정확한 값에서 멈춘다.
- [ ] 연못에 들어가면 핫바가 낚싯대 + 물고기 칸으로, 광산에서는 곡괭이 + 광석 칸으로 바뀌고, 나오면 씨앗으로 돌아온다.
- [ ] 입질 때 "!"와 (휴대폰) "당기기!" 버튼이 200ms 안에 나타나고, 버튼을 눌러도 물을 탭해도 당겨진다.
- [ ] 철광석을 칠 때마다 진행 막대가 한 칸씩 줄고, 고스트가 따라간다. 다섯 번째에 부서진다.
- [ ] 청크를 사면 상점이 닫히고 확장 배너, 진행 막대 "n/16", 방향 화살표가 4초 동안 보인다.
- [ ] 움직임 줄이기를 켜면 어떤 행동에서도 카메라가 흔들리지 않고 화면 번쩍임이 없다. 값은 그대로 바뀐다.
- [ ] 모든 글자가 14px 이상이고, 흰 글자 버튼은 18px 이상 굵은 글자 + 테두리다.
- [ ] 배너 3개가 동시에 오면 차례로 하나씩 보인다. 토스트는 하나만 보인다.

## Decisions (autonomous)

1. 핫바를 "자동 도구 칸 + 구역 아이템 칸"으로 정했다. 원탭 스마트 상호작용(서버가 행동을 고른다)을 유지하면서, 물고기·광석이 날아가 닿을 칸이 생긴다. 별도의 가방 버튼은 만들지 않는다.
2. 수확한 작물은 같은 작물의 씨앗 칸 금색 배지에 쌓는다(마인크래프트처럼 아이템이 자기 칸으로 간다). 바구니 요소를 따로 두지 않는다.
3. 오른쪽 기둥은 런타임에 점프 버튼 기준으로 위치를 잡는다(Roblox 문서 권장). 입질 때는 기둥을 숨기고 그 자리, 엄지가 이미 있는 곳에 당기기 버튼을 둔다.
4. 확장을 사면 상점을 닫는다. 축하가 패널 뒤에 묻히지 않게 하기 위해서다.
5. 성장·재고 타이머는 HUD에 두지 않는다(Pillar 1). 입질 창 막대만 예외다(컨셉이 허용한 유일한 도전).
