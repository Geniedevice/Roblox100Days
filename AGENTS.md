# Project instructions

This is an existing Roblox game project. Inspect the real place before implementing systems. Never replace it with an empty template.

Before Studio changes, ensure a local original backup exists. Use the official Roblox_Studio MCP, list available studios and verify the intended place. Start by reading scripts, hierarchy and output. Preserve existing gameplay unless a requested change requires it.

Use one AI writer per Studio session. Save Studio edits to the repository place file. Prefer rbxlx for readable Git diffs; never attempt to edit binary rbxl as text. Keep Luau source exports in src only after discovering the real hierarchy. Do not introduce Rojo sync over an existing place without an explicit mapping and backup.

Validate meaningful gameplay changes in Play mode, inspect Output and report what was actually tested. Keep secrets and local user settings out of Git. Publishing and remote pushes require user authorization.
